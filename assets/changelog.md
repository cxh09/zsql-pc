## v2.0.0 (2026-06-08)

这个新版本，代表着智拾清澜 app 的功能基本完整，使用体验更好了～

**功能新增：**

1. 基于高德地图 SDK 的导航功能重制作，页面更美观，性能更好
2. 新增多窗口功能，你可以拖动标签栏到标题栏之外的位置来使用单独的窗口打开
3. 增加了网络延迟检测功能，你可以随时检查网络的连通性

**优化：**

1. 性能优化：优化 WebView 资源管理，自动释放设备资源
2. 程序资源实现懒加载，降低了资源占用
3. 三方资源打包入程序：对于引用的三方静态资源直接打包进包体，页面加载更快更稳定
4. 暂时重构了软件 IPC 通讯部分，后续将继续优化
5. 动画优化：部分页面更美观，操作更加跟手
